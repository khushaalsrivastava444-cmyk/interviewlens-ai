# InterviewLens AI — Multimodal AI Mock Interview Coach

> **Production-grade student portfolio project** analyzing recorded technical interview responses, generating timestamped transcripts, computing measurable speaking analytics, grading answers against dynamic rubrics, and generating adaptive follow-up questions.

---

## 1. System Architecture

InterviewLens AI is designed as a **modular monolith** with clear architectural separation between:
- **Presentation Layer**: Next.js 14+ (App Router), TypeScript, Tailwind CSS, shadcn-inspired components, Recharts.
- **API & Orchestration Layer**: FastAPI with versioned `/api/v1` routes, Pydantic v2 schemas for strict contract enforcement, JWT OAuth2 authentication.
- **Persistence & Migration Layer**: SQLAlchemy 2.0 with PostgreSQL/pgvector in production and SQLite zero-dependency local development fallback; Alembic for database version migrations.
- **Media & Processing Pipeline**: Local private storage abstraction, FFmpeg/FFprobe audio/video extraction, bounded OpenCV frame sampling, SHA-256 integrity validation.
- **Speech & Evaluation Engine**: Timestamped transcription provider abstraction (Whisper-compatible), deterministic Python audio analytics (WPM, filler word density, pause ratio), rubric-based LLM evaluation, and stateful adaptive follow-up orchestration.

## 3. Database Schema

All models inherit from `app.database.Base` with UUID primary keys and UTC timestamps:

1. **`users`**: Candidate authentication, credentials, email index, target role, and experience level.
2. **`interview_sessions`**: Session state, title, category (10 supported technical domains), difficulty, question budget, score, and summary feedback.
3. **`questions`**: Question prompt, category, difficulty, question type (initial vs follow-up), parent question linkage, competencies, and scoring rubric.
4. **`uploaded_videos`**: File metadata, duration, SHA-256 checksum, resolution, audio presence, processing state (`uploaded`, `processing`, `completed`, `failed`).
5. **`transcripts`**: Normalized transcript text, confidence score, provider name, candidate edit status.
6. **`transcript_segments`**: Word/segment timestamps (start and end times in seconds) for video timeline scrubbing.
7. **`evaluations`**: Rubric criteria scores, strengths, missing concepts, recommended follow-ups, deterministic speaking metrics, and model audit metadata.
8. **`resumes`**: Extracted skills, projects, experience, and education for project defense questions.
9. **`learning_plans`**: Personalized action plans based on candidate knowledge gaps.

## 5. Quickstart & Local Verification

### Prerequisites
- Python 3.12+
- Node.js 20+ & npm
- FFmpeg & FFprobe (installed and accessible in PATH)

### Running Backend
```bash
cd backend
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
python -m alembic upgrade head
uvicorn app.main:app --reload --port 8000
```
Interactive API documentation: `http://localhost:8000/api/v1/docs`

### Running Backend Tests
```bash
cd backend
python -m pytest tests/ -v
```

### Running Frontend
```bash
cd frontend
npm install
npm run dev
```
Web Application: `http://localhost:3000`

### Docker Compose
```bash
docker-compose up --build
```
This spins up:
- PostgreSQL with `pgvector` on port 5432
- FastAPI backend on port 8000
- Next.js frontend on port 3000
